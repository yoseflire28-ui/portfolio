App interface · Case study

Lingua School

Lingua School is a student-management app for language schools. Its interface focuses on organizing student records and making common record-management and backup actions accessible on mobile.

View in Apps GitHub repository ↗ Download APK ↗

Design goals

Keep student lookup and record management clear, support quick access to individual profiles, and make backup and preferences easy to find.

Interface decisions

The student list puts search and key record details up front, with visible edit/delete actions and a persistent Students, Add Student, and Settings navigation. The add form groups related student information into sections, while Settings groups appearance, activity log, and CSV backup options.
